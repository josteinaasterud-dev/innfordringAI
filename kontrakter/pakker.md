# Pakker

Katalog over Agaas' pakker. Hver pakke er utformet slik at den oppfyller kravene i Vedlegg D.2 og kan utgjøre oppdragsspesifikasjonen for et regnskapsoppdrag.

Pakken kunden velger ved onboarding, dokumenteres i **Pakkebekreftelsen** og er en del av kundeavtalen. Arbeidsdelingen for oppgavene følger av Vedlegg H.

> Alle frister er angitt **relativt** til den lovbestemte fristen, ikke som datoer. Da endres ikke pakken når en frist flyttes.

## Holding

**For holdingselskap uten egen drift:** eier aksjer, mottar utbytte, yter eventuelt konsernbidrag eller lån. Ingen ansatte, ingen merverdiavgiftspliktig omsetning.

### Dette utfører Agaas

| Oppgave | Frekvens |
|---|---|
| Bokføring av bilag | Årlig, ved årsoppgjøret |
| Avstemming av bank og mellomværender | Årlig |
| Føring av aksjer, utbytte og konsernbidrag | Årlig |
| Utarbeide årsregnskap | Årlig |
| Utarbeide skattemelding og næringsspesifikasjon | Årlig |
| Utarbeide aksjonærregisteroppgave | Årlig |
| Klargjøre innsending til Regnskapsregisteret | Årlig |

### Dette gjør kunden selv

Leverer bilag og kontoutskrifter, fatter nødvendige styre- og generalforsamlingsvedtak (utbytte, konsernbidrag, fastsettelse av årsregnskap), og **signerer og sender inn** all rapportering, jf. Vedlegg F.

### Frister

| Hva | Frist |
|---|---|
| Kunden leverer årets bilag og kontoutskrifter | Senest [45] dager etter regnskapsårets slutt |
| Kunden leverer vedtak og protokoller | Senest [30] dager etter anmodning |
| Agaas klargjør aksjonærregisteroppgave | Senest [10] virkedager før lovbestemt frist |
| Agaas klargjør årsregnskap til styrebehandling | Senest [30] dager før lovbestemt frist |
| Agaas klargjør skattemelding | Senest [15] virkedager før lovbestemt frist |

### Ikke omfattet

Merverdiavgift, lønn, løpende rapportering gjennom året, konsolidering, transaksjonsbistand.

### Utløser oppgradering

| Hendelse | Konsekvens |
|---|---|
| Selskapet blir mva-registrert | Må over på Liten eller Medium |
| Selskapet får ansatte med lønn | Må over på Liten med lønnstillegg, eller Medium |
| Selskapet får løpende driftsinntekter | Vurderes; pakken forutsetter ingen drift |
| Bilagsvolum overstiger grensen | Tillegg per bilag, jf. Vedlegg D |

## Liten

**For selskap i tidlig drift:** merverdiavgiftspliktig omsetning, begrenset bilagsvolum, få eller ingen ansatte.

### Dette utfører Agaas

| Oppgave | Frekvens |
|---|---|
| Bilagstolkning, kontering og bokføring | Løpende |
| Bankavstemming | Månedlig |
| Reskontroavstemming kunder og leverandører | Månedlig |
| Periodisering og avsetninger | Månedlig |
| Anleggsregister og avskrivninger | Løpende |
| Periodeavslutning og melding om klargjort periode | Månedlig |
| Resultat- og balanserapport | Månedlig |
| Utarbeide mva-melding | Per termin |
| Utarbeide årsregnskap | Årlig |
| Utarbeide skattemelding og næringsspesifikasjon | Årlig |
| Utarbeide aksjonærregisteroppgave | Årlig |
| Klargjøre betalingsforslag | Løpende |
| Statusmøte | Årlig |

### Dette gjør kunden selv

Utsteder salgsfakturaer, godkjenner leverandørfakturaer, følger opp forfalte kundefordringer, godkjenner og frigir betalinger i bank, og **signerer og sender inn** all rapportering.

### Frister

| Hva | Frist |
|---|---|
| Kunden leverer bilag for perioden | Løpende, senest [7] dager etter periodeslutt |
| Kunden svarer på spørsmål om uklarheter | Innen [3] virkedager |
| Agaas melder perioden klargjort | Innen [10] virkedager etter periodeslutt |
| Agaas klargjør mva-melding | Senest [7] virkedager før lovbestemt frist |
| Agaas klargjør årsregnskap til styrebehandling | Senest [30] dager før lovbestemt frist |
| Agaas klargjør skattemelding | Senest [15] virkedager før lovbestemt frist |

### Tillegg

| Tillegg | Innhold |
|---|---|
| Lønn | Lønnskjøring, feriepenger, reiseregning og a-melding for inntil [3] ansatte |

### Ikke omfattet

Prosjekt- og avdelingsregnskap, konsolidering, budsjett og likviditetsprognose, opprydding i tidligere år.

### Utløser oppgradering

| Hendelse | Konsekvens |
|---|---|
| Bilagsvolum overstiger grensen | Tillegg per bilag; ved vedvarende overskridelse tilbys Medium |
| Flere enn [3] ansatte i lønn | Må over på Medium |
| Behov for prosjekt- eller avdelingsdimensjoner | Må over på Medium |
| Flere selskaper med konsolidering | Egen avtale |

## Medium

**For etablert selskap med jevn drift:** høyere volum, ansatte, behov for løpende styringsinformasjon.

### Dette utfører Agaas

Alt som inngår i Liten, og i tillegg:

| Oppgave | Frekvens |
|---|---|
| Lønnskjøring, feriepenger og reiseregning | Månedlig |
| Beregning av forskuddstrekk og arbeidsgiveravgift | Månedlig |
| Utarbeide a-melding | Månedlig |
| Prosjekt- og avdelingsregnskap | Løpende |
| Utvidet månedsrapport med nøkkeltall | Månedlig |
| Oppfølging av sykepenge- og refusjonskrav | Løpende |
| Statusmøte | Kvartalsvis |

### Dette gjør kunden selv

Som i Liten, og i tillegg: registrerer ansatte og lønnsbetingelser, godkjenner timer, fravær og reiseregninger, og utbetaler lønn i bank.

### Frister

| Hva | Frist |
|---|---|
| Kunden leverer bilag for perioden | Løpende, senest [5] dager etter periodeslutt |
| Kunden godkjenner timer og fravær | Senest [5] virkedager før lønnskjøring |
| Kunden svarer på spørsmål om uklarheter | Innen [2] virkedager |
| Agaas melder perioden klargjort | Innen [7] virkedager etter periodeslutt |
| Agaas klargjør a-melding | Senest [3] virkedager før lovbestemt frist |
| Agaas klargjør mva-melding | Senest [7] virkedager før lovbestemt frist |
| Agaas klargjør årsregnskap til styrebehandling | Senest [30] dager før lovbestemt frist |
| Agaas klargjør skattemelding | Senest [15] virkedager før lovbestemt frist |

### Ikke omfattet

Konsolidering og konsernregnskap, budsjettprosess, bistand ved bokettersyn, transaksjons- og omstruktureringsbistand, opprydding i tidligere år.

### Utløser egen avtale

| Hendelse | Konsekvens |
|---|---|
| Flere selskaper med konsolidering | Konsernavtale |
| Flere enn [15] ansatte | Egen prising av lønn |
| Vedvarende volum over grensen | Egen prising |

## Felles for alle pakker

| Forhold | Regulering |
|---|---|
| Kunden signerer selv | All innsending skjer under kundens egen elektroniske identitet, jf. Vedlegg F |
| Avvikshåndtering | Saker Regnskapsagenten flagger, avgjøres av autorisert regnskapsfører og inngår i prisen |
| Arbeid utenfor pakken | Faktureres etter medgått tid; timepris opplyses og varsles før arbeid påbegynnes, jf. Vedlegg D.6 |
| Volumoverskridelse | Kunden varsles, og tillegg per enhet påløper. Ved vedvarende overskridelse tilbys større pakke |
| Nedgradering | Får virkning fra utløpet av inneværende [måned/termin], og kunden opplyses om hvilke oppgaver som da tilfaller kunden selv |
| Oppstart midt i året | Opprydding i inngående balanse og tidligere perioder inngår ikke; prises særskilt etter gjennomgang |
